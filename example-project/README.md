# Example folder

Everything you need for the course activities. None of the live activities require you to run code or install extra software: you only open and inspect files here (and explore examples in your web browser).

| Folder or file | What it is | Used in |
|---|---|---|
| `messy-project/` | A project with a messy layout, vague notes and duplicate files. Open it and see what you can work out | Sections 1 and 2 |
| `tidy-project/` | The same project with good habits: clear folders, a README, a data dictionary, and a Quarto report (`report.qmd`) rendered to HTML, PDF and Word in `outputs/` | Sections 1 and 2 |
| `environment-demo/` | Small projects in Python (`python-example/`, with `uv.lock`) and R (`r-example/`, with `renv.lock`) for peeking inside a real lock file — plus optional steps to run the 2023-vs-today environment demo yourself | Section 3 |
| `checklist.pdf`, `checklist.docx` | A one-page checklist to tick for your own project | Section 4 |
| `capstone-answer/` | A finished answer to the optional capstone exercise, in R (`r/`) and Python (`python/`), with lock files and rendered reports in `outputs/`. Try the exercise first! | After the course |
