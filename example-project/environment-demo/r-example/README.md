# Penguin body mass (R)

A small analysis that prints the average body mass of each penguin species and saves a bar chart using `ggplot2`. It is used in **Section 3 (Virtual environments)** for the lock file activity (and as an R alternative for practising environments with [renv](https://rstudio.github.io/renv/)).

## Contents

- `data/penguins.csv`: the penguin measurements
- `code/analysis.R`: loads `ggplot2`, prints the average body mass of each species, and saves a chart to `outputs/`
- `renv.lock`: the lock file recording the exact versions of `ggplot2` and every package it relies on

## Activity: peek inside the lock file (no coding needed)

Open `code/analysis.R` and `renv.lock` in any text editor:

1. `code/analysis.R` only asks for **1 package** (`library(ggplot2)`). Scroll through `renv.lock` — how many packages are actually recorded inside `"Packages"` (such as `cli`, `rlang`, `scales`, `vctrs`), and why?
2. Search `renv.lock` for `"ggplot2"`. Which exact version was recorded, and which version of R is listed at the top?

## Optional: rebuild the environment yourself (needs R and renv)

If you want to try `renv` on a copy of this folder in RStudio or Positron (`install.packages("renv")` first if you don't have it):

1. Open the folder in R, and run `renv::restore()`. `renv` reads `renv.lock` and installs those exact package versions into a project-specific `renv/library/` folder, without changing your other R projects.
2. Run `source("code/analysis.R")`: it prints the table and saves `outputs/body_mass.png`.

When sharing an R project, send the code, data, README and `renv.lock` (plus `.Rprofile`, `renv/activate.R` and `renv/settings.json` if generated by `renv::init()`). **Never send `renv/library/`.** Note that `renv.lock` records the R version, though `renv` does not install R itself — write the R version in your README too.
